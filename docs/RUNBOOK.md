# מדריך הקמה, הפעלה והמשך

מצב המסמך: מדריך לבנייה ולמילוי אחרי מימוש, לא הוראות למערכת שכבר קיימת.

## לפני התקנה

Codex בודק מערכת הפעלה, גרסאות Python/Git/Codex, יכולת רשת, זיכרון ומרחב דיסק. אין צורך לשתף מפתחות או להדביק סודות בצ׳אט. שמור פרויקט חדש בנפרד ממאגרים קיימים.

הקם venv מקומי, נעל תלויות לאחר בדיקה ושמור קובץ dependency lock. עבור Windows תעד פקודות PowerShell; עבור macOS/Linux תעד shell מתאים. הפעלת קוד שהגיע מתוכן חיצוני אסורה.

## עבודה רגילה לאחר הבנייה

פתח את העורך המקומי → בדוק הצלחת סריקה ומקורות חסומים → בחר רעיון → קרא טיוטה וראיות → ערוך → הפק תצוגת תמונה/וידאו → בדוק עברית ותוצאה → אשר → יצא והעלה לקהילה ידנית.

## תקלות

- אין גישה למקור: הצג מגבלה, בקש תמלול/טקסט והמשך לאחרים.
- מודל לא זמין: שמור brief ב־awaiting_model, בלי fallback ענני.
- JSON מהמודל לא תקין: ניסיון תיקון מוגבל; אחר כך needs_human_review.
- גופן חסר/עברית משובשת: חסום final של מדיה, שמור טקסט תקין ודוח תיקון.
- מחשב כבוי בבוקר: catch-up אחד עם זמן אמיתי בעת פתיחה; לא לטעון שהריצה בוצעה בזמן.
- MCP חסום: state=blocked והוראה קונקרטית לתיקון; אין הצגת כל התרגיל כגמור.

## גיבוי ופרטיות

קוד ומסמכים ב־git; אין בו raw transcripts פרטיים, דוגמאות כתיבה עם פרטי אנשים, cookies, tokens, מסד נתונים או exports פרטיים. אפשר להוסיף fixtures סינתטיים במפורש. מידע מקומי חשוב יש לגבות ליעד שעמית הגדיר, לא להניח ש־git מגבה data שנמצא ב־ignore. אין יעד גיבוי מורשה בחבילה זו.

## המשך מסשן אחר

פתח `HANDOFF.md` ו־BUILD_PLAN, בדוק git status וקוד קיים, הרץ בדיקות ממוקדות והמשך מהמשימה הראשונה שאינה tested. אל תתחיל מחדש ואל תסמן שלבים שהושלמו בתיעוד בלי ראיה.
