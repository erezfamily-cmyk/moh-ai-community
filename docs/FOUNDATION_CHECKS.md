# תוצאות בדיקת התשתית — 4.11.2026

## מה הורץ בפועל

- Python 3.12.14 על Linux.
- `PYTHONPATH=src python3 -m unittest discover -s tests -v`: שישה טסטים עברו.
- `PYTHONPATH=src python3 -m moh_ai doctor`: הצלחה; Git ו־FFmpeg מזוהים; Asia/Jerusalem זמין.
- `init-db` ואחריו `ingest` על קובץ סינתטי ובתיקיית נתונים זמנית: הצלחה.
- בדיקת קישורי Markdown מקומיים בכל המסמכים: אין קישורים חסרים.
- כל קובצי TOML נותחו בהצלחה באמצעות tomllib. זה אינו מוכיח טעינה ב־Codex.
- קובץ ZIP נבדק באמצעות testzip; ללא שגיאת CRC.

## מה נבדק בטסטים

דיווח מצב אמין ב־doctor, שימור עברית, ייבוא כפול אידמפוטנטי, הפרדת טקסט מתמלול במקור הנתונים, דחיית קובץ ריק, שגיאה מפורשת לקובץ חסר ודחיית קובץ גדול מדי. שימור עברית ואידמפוטנטיות נבדקו באותו טסט.

## מה לא נבדק/לא מומש

UI, fetch מקור רשת, מודל מקומי, יצירת פוסטים, רינדור תמונה/סרטון, חיבורי MCP, טעינת סקילים, טעינת תצורות agents בלקוח, סריקה אוטומטית או תזמון מקומי. פקודות Windows לא הורצו. זמינות משימת הבוקר בענן בריצה עתידית לא נבדקה.

בדיקות אלה מוכיחות רק את שלד הקוד ושלמות מסמכי החבילה. דרישות הקבלה של המוצר והתרגיל עדיין דורשות בנייה והרצות אמיתיות.
