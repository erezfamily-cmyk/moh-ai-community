# מדיניות אפס עלות שירותים

## משמעות מעשית

היעד הוא ללא תשלום רישוי/שירות נוסף להפעלה: ללא API בתשלום, ללא מנוי חדש, ללא כרטיס אשראי, ללא ניסיון חינמי וללא קרדיטים מתכלים שהמוצר תלוי בהם. מחשב קיים, חשמל, אינטרנט, נפח אחסון וזמן אדם עדיין נדרשים; חומרה חסרה אינה נחשבת חינם.

הסקיל הוא הוראות; MCP הוא פרוטוקול חיבור. אף אחד מהם אינו הופך מודל או שירות לחינמי. גם Codex והסאב־אייג׳נטים צורכים מכסה או משאבי מודל. אין לבסס את הטענה ״הכול חינם״ על מנוי Team קיים.

## שני מסלולי הפעלה

| מסלול | מה עובד | מגבלה |
|---|---|---|
| מקומי מלא — היעד | איסוף, ניתוח וטיוטות בעזרת מודל מקומי בעל רישיון מתאים; מדיה בכלים מקומיים | דורש בדיקת חומרה, התקנה ואיכות עברית; אינו מובטח לפני benchmark |
| מקומי + אישור/כתיבה ידנית — fallback | איסוף, בחירה מוקדמת, brief ותבניות; עמית משלים כתיבה ידנית או בסשן Codex שיש לו גישה אליו | אינו יצירת פוסטים יומית אוטונומית מלאה; להציג `awaiting_model` |

אין לעבור אוטומטית ממודל מקומי לענן כאשר המודל אינו זמין.

## בחירת רכיבים

עדיפות לפייתון, SQLite, ממשק HTML מקומי, רינדור בדפדפן ו־FFmpeg בבנייה בעלת רישיון מתאים. אלה כיווני מימוש ולא רשימת רכיבים שכבר מותקנים. לפני שימוש אמת בתיעוד הרשמי ובגרסה בפועל: רישיון, תמיכה בעברית, דרישות חומרה, יכולת יצוא וסימן מים. מודל, runtime, גופן ומוזיקה דורשים רישוי נפרד.

חיפוש: RSS, אתרים רשמיים ורשימות ערוצים ציבוריים. אין תלות ב־search API בתשלום. אין הבטחת חיפוש רשת כולל במסלול המקומי; מדובר בסריקת מקורות מוגדרים. דפי רשת ציבוריים עלולים לחסום קריאה.

## Cost guard מחייב

- ברירת מחדל `STRICT_FREE=true`, `MODEL_MODE=manual` עד בחירת מודל תקין.
- ספק מודל מותר: תהליך מקומי או endpoint ב־loopback בלבד, מאומת בנפרד מנתיבי ה־HTTP לאיסוף מקורות ציבוריים.
- reject לכתובת מודל חיצונית, לכל fallback ענני ולתלות במפתח API של ספק מודל.
- מקור תוכן יכול להיות HTTPS ציבורי שהוגדר; אין הרשאה לתשלום דרך המקור.
- בדיקות יוכיחו שאין בקשת מודל לרשת גם כשיש שגיאה, timeout או חסר קובץ.
- מגבלות מקומיות: עד 20 מקורות לריצה, עד 5 הצעות, שני workers לאיסוף, worker אחד למודל/וידאו כברירת מחדל. המגבלות ניתנות לשינוי בהגדרה, ללא תשלום.

## יומן אימות עלויות

לכל רכיב רשום: שם וגרסה, URL רשמי, רישיון, האם דורש חשבון/מפתח/כרטיס, quota, תאריך בדיקה, מצב verified/blocked. יש למלא בפועל לפני קבלת שלב. שורת ״חינמי״ בלי ראיה אינה מספיקה.
