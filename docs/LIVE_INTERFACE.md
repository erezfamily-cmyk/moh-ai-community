# הממשק החי של מוח AI

קישור פרטי פעיל: https://moh-ai-editorial-lab.mentorysai-c-6274.chatgpt.site

## מה אפשר לעשות עכשיו

פתיחת הפיילוט, עריכת פוסט וכותרת, שמירת גרסאות והיסטוריה, הוספת כתבה/טקסט/תמלול, תיעוד טענה וקטע ראיה, ביקורת ידנית ואישור טקסט, יצירת כרטיס PNG, הורדת Markdown וגיבוי/שחזור JSON. אין פרסום לרשתות.

הנתונים החדשים נשמרים בדפדפן ובמכשיר הנוכחיים בלבד. אין סנכרון אוטומטי עם מכשיר אחר או עם SQLite של תוכנת Python. העברה בין מכשירים מתבצעת בגיבוי JSON. יבוא גיבוי מאפס אישורי טקסט, כדי לדרוש אישור מחדש.

אין בממשק מנוע AI, קריאת כתבות אוטומטית מ־URL, סריקת בוקר או סרטון. שלוש זוויות הבית מבוססות על מקור הפיילוט היחיד ולא מוצגות כאיסוף חדשות שבוצע היום. בדיקת מבנה היא היוריסטיקה ולא ביקורת AI. דוגמאות כתיבה נשמרות כהכנה להמשך, לא כאימון מודל.

## כניסה ופרטיות

האתר פורסם בגישת בעלים בלבד. פתיחה בדפדפן הבדיקה הציגה שער ״Log in to access״, ולכן המשתמש ייתכן שיידרש להתחבר דרך ChatGPT. לא הורחבה גישה לציבור, לקבוצה או למנחה. קישור אינו מעניק הרשאה.

האירוח תלוי בחשבון ChatGPT/Sites הקיים; אין הבטחת גישה אחרי סגירת החשבון ואין התחייבות לאירוח חינם לנצח. לא הוסף API בתשלום, מפתח או מנוי חדש. קוד האתר וגיבויי המשתמש ניתנים להעברה.

## קוד והמשך פיתוח

העותק ב־`live-web/` מכיל את מקור הגרסה שפורסמה. הוא סטטי וללא תלויות build. הוא נפרד מ־`src/moh_ai/static/`, שהוא הממשק המקומי ל־Python; אין להחליף אחד בשני בלי לתכנן אחסון וחוזים.

אתר Sites: `appgprj_6aeb7a7966288191855d6a9e5d0bff2c`.

מקור האירוח פורסם מ־commit `66a0efd91545fe79e5ce40e151a1515c89a7cc90`. עותק GitHub אינו מפעיל פריסה אוטומטית. בעדכון אתר חי יש לפתוח את האתר הקיים עם הכלים המתאימים, לשמר זהות והרשאות ולהשתמש בתהליך הפרסום הנתמך, ולא ליצור אתר חדש.

## בדיקות שבוצעו

- תשע בדיקות ליבה ב־Node: תקינות גיבוי, עברית והיסטוריה, שדות/קישורים/ראיות לא תקינים, מקור חסר ותנאי אישור.
- בדיקת תחביר JS.
- Cloud Browser בסביבת preview: דף בית, פתיחת עורך, שינוי כותרת ושמירת גרסה, רענון ושימור נתונים, גרסאות קודמות והורדת PNG.
- בדיקות רוחב תוכן 390/768/1440 באמצעות iframes: בכל אחד scrollWidth שווה clientWidth.
- תצוגת הבית במחשב נבדקה חזותית. לא בוצעה בדיקה על טלפון פיזי.
- טופס הוספת מקור ושחזור קובץ מלא טרם נבדקו בדפדפן מקצה לקצה; חוזי הנתונים שלהם נבדקו בבדיקות הליבה.
- פרסום Sites החזיר succeeded. דפדפן בדיקה ללא התחברות נתקל בשער הכניסה; אין טענה שנבדק תהליך ההתחברות לפרודקשן.

40 בדיקות Python מן היישום הקודם אינן תשע בדיקות האתר ואינן מחליפות אותן.

## משימות הבאות

לבדוק את הקישור בטלפון ובחשבון המשתמש, להשלים בדיקות טופסי מקור וגיבוי מקצה לקצה, ואז לחבר איסוף מקורות ומנוע תוכן במסלול שעומד במדיניות העלות. לתכנון אחסון בין מכשירים יש צורך בהחלטה מפורשת; כרגע משתמשים בגיבוי ידני.
