## בדיקות מדיה וממשק

בדוק רוחבי 390, 768 ו־1440; אין גלילה אופקית בלתי רצויה, העתקת עברית תקינה, קישורים לחיצים, הודעות מצב מובנות. PNG: גודל, קריאות, שבירת שורות, אנגלית מעורבת ו־RTL. MP4: codec/משך/מידות, כתוביות עברית, זמן קריאה והיעדר פריימים ריקים. צפייה/בדיקה חזותית אנושית נדרשת; ffprobe לבדו אינו בודק איכות הסבר.

## בדיקות שילוב

- fixture סינתטי לבדיקות שחוזרות ללא רשת; לסמן synthetic ולא להשתמש כהוכחת מחקר אמיתי.
- E2E אחד: מקור אמיתי → ראיות → טיוטה → ביקורת → תיקון → תמונה → אישור → יצוא.
- E2E נוסף לווידאו לאחר B12.
- MCP חיצוני: קריאה אמיתית ותגובה. MCP מקומי: handshake וקריאת כלי באמצעות לקוח. סקיל: טעינה והפעלה מפורשות.
- יש להריץ את פקודת ההפעלה המתועדת בתיקייה נקייה/סביבה חדשה ככל שניתן, בלי לעקוף על ידי קבצים פרטיים של המפתח.

## רובריקת תוצר

1–5 לכל מדד: דיוק, בהירות, תועלת, קול, איכות מדיה. יעד ≥4 בכל מדד וללא טענות מרכזיות לא נתמכות. מדד קול דורש אישור עמית. מבקר AI אינו משתמש אמיתי ואינו מקור עובדתי נוסף.

## ראיות

מלא `templates/TEST_REPORT.md` ו־`templates/REVIEW_AND_REVISION.md`: פקודה אמיתית, זמן, סביבת הרצה, תוצאה, כשל אם יש וקישור לתוצר. רשום בנפרד tests passed, not run ו־blocked. אין להמציא ממצאים, צילומי מסך, זמן שנחסך או נתוני מעורבות קהילה.
