## מה השתנה בממשק החי

טיפוגרפיית מערכת, היררכיה וריווח, ניגודיות משופרת, יעדי מגע גדולים, תגובה מיידית ללחיצה, header שקוף במידה וניווט מובייל תחתון. העדפות reduced motion/transparency/contrast מקבלות חלופות סטטיות וקריאות. נשמרה הזהות הירוקה של מוח AI ולא נוסף מיתוג Apple.

אייג׳נט נפרד השתמש בסקיל לסקירת המקור. בעקבות הממצאים תוקנו מיקוד textarea ומעבר מסכים, תוויות dialogs, סמנטיקת tabs וניווט מקלדת, disclosure expanded state, חיווי כשל שמירה ואזהרת יציאה, שמירת דוגמאות קול, ושמירה מפני איבוד עריכות בטופס. [דוח הסקירה](../research/design/APPLE_DESIGN_REVIEW.md) מתעד את המצב לפני התיקון; אינו מציג את הממצאים כפתוחים בהכרח אחרי תיקונם.

## איסוף מקורות אמיתי — שלב ראשון בסדר העדיפויות

נוסף `src/moh_ai/discovery.py`, ללא תלות צד שלישי או API בתשלום.
נבדקו שלושת הפידים הרשומים ב־`config/discovery_sources.json`: OpenAI News, Google AI Blog ו־Hugging Face Blog.
בהרצה אמיתית נקראו 1,020 רשומות פיד ונבחרו ארבעה מועמדים מהחלון של עד 72 שעות. ברירת המחדל מעדיפה 24 שעות, מדלגת על תאריך לא ידוע/עתידי, מסירה כפילויות ומגבילה ייצוג של מקור בודד.

[הדוח](../research/discovery/latest-report.json) ו־[ראיות רשת](../research/discovery/network-evidence.json) נשמרו. זהו איסוף RSS אמיתי, לא נתוני דוגמה. הפעלת proxy ירשה את תצורת הסביבה הרגילה; לא בוצעה עקיפת רשת. היעדים מוגבלים לפידים ולמארחים מאושרים. הפרוקסי פותר DNS למארחים קבועים; לא נטען שבוצע IP pinning במסלול הזה.

פקודה משורש המאגר:
```bash
PYTHONPATH=src python3 -m moh_ai.discovery --output research/discovery/latest-report.json
```
ראו [מדריך האיסוף](../research/discovery/README.md) לאפשרויות Windows, מגבלות ומבנה הדוח.

## החיבור לממשק החי

נוסף מסך ״גילוי מקורות״ וקישור אליו מהבית וממסך המקורות. הדוח המוצג הוא snapshot מהרצה, עם זמן איסוף, מקור, תאריך פרסום, סיבת בחירה וכיוון ראשוני לפוסט. הוא אינו מתעדכן אוטומטית בכל בוקר. פרסום דוח חדש באתר דורש עדכון נתוני האתר ופרסום גרסה; ריצת CLI לבד אינה מסנכרנת אותו לאתר.

כל פריט מסומן `metadata_only`, `not_verified` ו־`needs_full_text` או `needs_transcript`. המעבר לטופס מעביר כותרת וקישור אך משאיר תוכן ריק ודורש הוספת תוכן אמיתי. הזוויות נבחרות לפי כללים ואינן מסקנות מתוך כתבה שנקראה. אין כתיבת פוסט אוטונומית מכותרת.

## בדיקות ומה לא הושלם

56 בדיקות Python עברו, כולל 16 חדשות לאיסוף. 14 בדיקות Node עברו, כולל בדיקות דוח אמיתי ודחיית מצב שמציג metadata כאימות.
ב־Cloud Browser נבדקו מסך הדוח, העברה לטופס עם תוכן חסר, tabs נגישים ומיקוד. ב־iframes נבדקו רוחבי בית 390/768/1440 ללא overflow; עמוד גילוי נבדק ב־390 ללא overflow. ניווט מובייל נמדד כ־59×86 פיקסלים בקירוב ליעד.

העדפות מערכת לתנועה/שקיפות/ניגודיות וכשל localStorage נבדקו במקור אך לא הודמו בדפדפן. לא בוצע audit נגישות מלא, בדיקת טלפון פיזי או כל תרחישי הקלט האפשריים.

עדיין נדרשים: קריאת גופי כתבות/תמלולים חדשים, מודל מקומי ליצירה אוטומטית, דוגמאות ואישור הקול של עמית, תזמון איסוף קבוע וחיבורו לאתר, סנכרון בין מכשירים וסרטון. ממשיכים בסדר: גילוי → הצעות → קול → אימות → המשכיות → וידאו.
