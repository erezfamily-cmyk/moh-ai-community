## פקודות יעד שיש לממש

ממש CLI אחיד מתחת ל־`python -m moh_ai`. שמות מוצעים: doctor, init-db, ingest, analyze, draft, review, render-image, render-video, daily, serve, mcp. הפקודות הן חוזה בנייה ולא פקודות שכבר קיימות בחבילה. ב־doctor וב־help חובה לפעול ללא מודל וללא רשת. תעד את התחביר האמיתי ב־RUNBOOK לאחר המימוש.

## בחירת מודל מקומי

אל תבחר מספר פרמטרים או שם מודל לפי ניחוש. בדוק RAM/VRAM, רישיון ושפות; הרץ על שתי כתבות ותמלול אחד. השווה מול ראיות: האם נוספו טענות, האם העברית סבירה, זמן, זיכרון וקונטקסט. אם אין חומרה מתאימה, מסלול ידני נשאר תקין אך האוטומציה המלאה מסומנת blocked. אין להציע רכישת חומרה כהשלמת דרישת החינם.

## עבודה עם git

בדוק אם התיקייה כבר מאגר. במאגר חדש צור ignore לנתונים/סודות לפני הוספת קבצים. בצע commits קטנים ליכולות שעובדות. אין להגדיר remote על מאגר Travel4Fun או Amit Photos. עמית אישר את המאגר הנפרד `https://github.com/erezfamily-cmyk/moh-ai-community.git`, שנוצר כפרטי. זהו יעד ה־remote של הפרויקט. אל תשנה אותו למאגר אחר ואל תעלה נתוני משתמש פרטיים.
