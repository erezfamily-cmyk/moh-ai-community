# איסוף מקורות — מקטע B10, 4.11.2026

## מה ממומש ונבדק

איסוף ידני בתוך היישום הקיים, RSS 2.0 / Atom / RSS RDF וקישורי HTTPS ציבוריים מוגדרים. ללא התקנת dependency, חשבון, מפתח API, ספק מודל, שירות חיפוש או fallback ענני. הספרייה הסטנדרטית של Python ו־SQLite הקיימים משמשים גם כאן. אין רכיב חדש בעל מכסה או עלות שירות. מחשב, חשמל, אינטרנט ואחסון עדיין נדרשים.

הפעלה: `python start.py`, לשונית **רעיונות מהמקורות**. פתחו ״הגדרת מקורות ציבוריים״, בדקו את הגישה במחשב והפעילו מקור באמצעות `enabled: true`. הכפתור ״איסוף עכשיו״ מפעיל ריצה אחת. אין ריצה בעת פתיחת המסך או בהפעלת השרת. פתיחת המסך קוראת רק את SQLite. שלושת פידי הספקים המצורפים הם **מועמדים כבויים**, ולא רשימת מקורות מאומתת. ניסיון גישה בסביבת הפיתוח הסתיים ב־`Cannot resolve source host` בשלושתם; פורמט/גישה/תנאי שימוש חיים לא אומתו כאן.

אפשר להחליף רשימת מקורות ב־JSON דרך המסך או CLI. המקורות והשינויים נשמרים ב־SQLite בתיק הנתונים, מחוץ ל־git. אין עריכת סודות או חיבור חשבונות.

```json
[
  {"name":"מקור שבדקתי", "url":"https://example.org/feed.xml", "kind":"rss", "authority":"unknown", "enabled":false}
]
```

`example.org` כאן הוא דוגמה בלבד. `authority` הוא primary/secondary/unknown: סיווג ידני של המפרסם, **אינו אימות עובדות**. סיווג primary לא עובר אוטומטית לקישור מפיד או redirect לאתר אחר.

| kind | פעולה | בסיס ראיות |
|---|---|---|
| rss | גילוי קישורים מפיד וקריאת הקישורים עצמם | כותרת/תאריך מהפיד הם metadata, אינם תחליף לקריאת כתבה |
| link | קריאת טקסט/HTML נגיש | full_text = הטקסט שחולץ בפועל; שלמות HTML אינה מובטחת |
| video / social | קריאת עמוד ציבורי בלבד | description_only; ללא רעיון המסכם את תוכן הסרטון |
| transcript | קישור המגיש VTT/SRT | transcript, עם זמנים ובלי טענת צפייה |

דפי YouTube, שורטים ורשתות חברתיות מוכרות מסומנים כתיאור בלבד גם כשהגיעו מפיד רגיל. תמלול טקסט רגיל אפשר להדביק במסך המקורות הקיים; URL מסוג transcript חייב להגיש VTT/SRT כדי שלא נייחס דף HTML לתמלול. תמלול אמיתי נשאר תמלול גם תחת kind=video. אין הורדת וידאו או ניתוח חזותי אוטומטי. דף ציבורי מרשת חברתית נשמר כאן באופן שמרני כתיאור; תמיכה בהפרדת גוף פוסט מאומת מתבנית האתר היא משימת המשך.

## אמינות, ראיות ורעיונות

כל טקסט שנקרא נשמר עם כתובת מבוקשת וסופית, מועד קריאה UTC, תאריך פרסום אם סופק, raw/content hashes, בסיס הניתוח, מגבלות וקטעי תמלול כשקיימים. נשמר גם תיק ראיות במערכת העריכה הקיימת. C1 הוא **קטע שנאסף וטרם נוסח כטענה**, במצב source_claim_only. אין אישור אוטומטי. הקטע חייב להופיע בטקסט; בתמלול locator כולל זמן כשקיים. בחירת רעיון טוענת למסך המקור כדי שהמשתמש ינסח ויבדוק טענה לפני כתיבה. גרסאות ואישורים קיימים אינם משתנים.

לגילוי RSS נשמרים URL סופי, hash, מועד קריאה והערכים שחולצו מהפיד. אלה ראיות metadata, ולא טענה שנקראה כתבה. שגיאה כוללת URL, שלב והודעה; בסיס unread כשלא נקרא תוכן. לא נוצר טקסט חלופי מומצא. שגיאת מקור אחד אינה עוצרת אחרים. XML עם DTD/entities נדחה. אין עקיפת התחברות, CAPTCHA או paywall; יש זיהוי היוריסטי מוגבל לדפי חסימה נפוצים. חסימה לא מוכרת עלולה לדרוש בדיקה אנושית.

דירוג **היוריסטי זמני**, לא מודל ולא בדיקת אמינות סמנטית: עד 60 נקודות לשלוש קבוצות מילות מפתח (AI, למידה/פעולה, כלי); 15 למקור ראשוני באותו host או 5 למשני; 15 לפרסום ביומיים האחרונים. ללא התאמת AI או בתיאור בלבד התקרה 25. סף רעיון 35. שיטה זו מחליפה כרגע את רובריקת חמשת המדדים המתוכננת ב־SOURCES; אינה מיישמת אותה במלואה. הנימוקים גלויים בכרטיס.

עד חמש הצעות עם כותרת מקור, זווית מוצעת בעברית, קטע ראיה, תאריך, בסיס, סיבה להתאמה, פעולה ו־brief להמחשה. הראשונה מומלצת לפי ציון ההתאמה; כל הטענות עדיין טעונות אימות. עד שתי הצעות מאותה קטגוריה; לא ממלאים מכסה. כותרות מקור עשויות להישאר בשפת המקור. **אין פוסט שנוצר אוטונומית או תרגום מלא ללא מודל**: generation_status=awaiting_model. ההנחיות הן תבניות עריכה מסומנות, לא סיכום מומצא.

פרסום מזוהה מעל 72 שעות או בעתיד אינו מקבל רעיון בוקר; עד 48 שעות מקבל תוספת ניקוד, וב־48–72 שעות נשאר כשיר עם תאריך. תאריך חסר/לא תקין/ללא אזור זמן אינו מקבל ניקוד עדכניות ומוצג כפי שסופק, בלי להחליפו במועד הקריאה. סדר הקריאה מעדיף פריטים עדכניים מתוארכים. אין הבטחה שכל הפיד נסרק.

## כפילויות, גבולות והתאוששות

- עד 20 מקורות, עד 20 רשומות מכל פיד ועד 20 קישורי תוכן בסך הכול בכל ריצה, באיסוף סדרתי. עד 20 בקשות גילוי ועוד 20 בקשות תוכן, לפני redirects המוגבלים ב־fetcher. יתר המועמדים נספרים כ־deferred.
- HTTPS בלבד, DNS ציבורי ו־IP pinning, בדיקה מחדש בכל redirect, בלי credentials/cookies/proxy. 2 MiB לתגובה, עד 10 שניות לבקשה כולל גוף ו־redirects, למעט מגבלת DNS הניידת הקיימת. טקסט שחולץ מעל 200,000 תווים נדחה במפורש, בלי חיתוך שקט.
- מנרמלים fragment ופרמטרי מעקב מוכרים, שומרים פריט לפי URL+content hash. ראיות בגרסאות משתנות נשמרות בנפרד.
- רעיונות מנוכים גם לפי hash תוכן וכותרת מנורמלת, בתוך ריצה ובין ריצות. רעיון שכבר הוצע לא מוצע שוב. זו השוואה שמרנית ומילולית: אינה מזהה בוודאות אותה הכרזה בניסוחים שונים, ועלולה להסתיר עדכון בעל כותרת זהה. אין פתרון סמנטי ללא מודל.
- מפתח יום Asia/Jerusalem, נעילת SQLite עמידה בפני ריצות מקבילות גם משני תהליכים. ריצה נוספת באותו יום מחזירה תוצאה שמורה בלי רשת. שינוי הגדרות או refresh מפורש מאפשר ריצה חדשה; אין ביטול dedupe של רעיונות.
- אין retry אוטומטי. אפשר לסמן איסוף חוזר לאחר שגיאה. כשל בלתי צפוי שומר דוח failed; תהליך שנהרג עשוי להשאיר running. רק לאחר סגירת התהליך הישן מפעילים daily-reset; אין השתלטות אוטומטית שעלולה להכפיל ריצות.
- דוחות היסטוריים נשמרים ב־SQLite. המסך מציג עשר ריצות אחרונות והתוצאה האחרונה. ניהול נפח/מחיקה/סקירת כל ההיסטוריה הם המשך; תהליך מקומי שנעצר אינו מתקדם מעצמו.

## CLI

משורש המאגר, עם `PYTHONPATH=src` (ב־PowerShell הגדירו `$env:PYTHONPATH="src"`):

```bash
python -m moh_ai daily-sources
python -m moh_ai daily-sources --file my-sources.json
python -m moh_ai daily
python -m moh_ai daily --force
python -m moh_ai daily-status
python -m moh_ai daily-reset
```

`--data-dir` הוא דגל כללי לפני הפקודה. daily-status ו־daily-sources ללא file אינם פונים לרשת. daily-reset מיועד רק להתאוששות כמפורט לעיל. אין פקודת התקנת מתזמן ואין workflow מתוזמן חדש.

## היחס למשימת הבוקר

ב־4.11.2026 אומת בקריאה בלבד שמשימת ChatGPT **״רעיונות למוח AI״ מופעלת**, מתוכננת DAILY החל מ־5.11.2026 ב־08:00 Asia/Jerusalem במצב flexible_schedule. `last_run_time` ו־`next_run_time` חזרו null; אין הוכחת הרצה או מסירה ואין לקבוע שעה מובטחת. המשימה קיימת בחשבון, אינה תהליך ביישום ואינה מסנכרנת ל־SQLite.

לא שינינו, השהינו או יצרנו משימה. התזמון המקומי נשאר disabled. לפני מעבר לאיסוף אוטומטי צריך להציג לעמית מנגנון אחד נבחר, זמנו והיחס למשימה הקיימת, ולקבל אישור מפורש. הפרסום לקהילה נשאר מחוץ למסלול.
