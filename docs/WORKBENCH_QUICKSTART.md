# הפעלת גרסת העבודה הראשונה

> עדכון נוסף 4.11.2026 — איסוף מקורות ידני ממומש ביישום הקיים: RSS/Atom, קישורים, ראיות, dedupe, דירוג זמני ועד חמש הנחיות לרעיונות, ללא מודל. 59 בדיקות עברו. [הפעלה ומגבלות](DAILY_COLLECTION.md), [ראיות בדיקה](DAILY_COLLECTION_TESTS.md). אין תזמון מקומי פעיל. שלושת מקורות ברירת המחדל הם מועמדים כבויים עד בדיקת גישה במחשב היעד; ניסיון גישה חי כאן נכשל ב־DNS. אין פיילוט איסוף חי או QA חזותי חדש. התיאורים הישנים בהמשך של ״אין סריקה״ מתייחסים למצב לפני מקטע זה; תזמון, מודל ו־MP4 עדיין חסרים.

דורש Python 3.11 ומעלה. הממשק והליבה משתמשים בספרייה הסטנדרטית בלבד. אין צורך במפתח API, הרשמה לשירות חדש או התקנת מודל כדי לפתוח את המערכת.

## הפעלה במחשב

```bash
git clone https://github.com/erezfamily-cmyk/moh-ai-community.git
cd moh-ai-community
python start.py
```

אם שם הפקודה במחשב הוא python3, השתמש בו במקום python. פתח http://127.0.0.1:8765 בדפדפן באותו מחשב. ניתן לשנות פורט: `python start.py --port 8766`.

המאגר פרטי ודורש גישת GitHub מורשית; אין להדביק token בשורת פקודה. עותק קיים יש לעדכן בענף המתאים בלי לדרוס שינויים מקומיים.

## הפיילוט

לחץ ״פתיחת הפיילוט הראשון״. שתי גרסאות עם ביקורות יופיעו בספרייה. פתח v2, קרא את המקור והביקורת, ערוך ושמור גרסה חדשה אם צריך. גרסה חדשה אינה מקבלת אישור אוטומטית. יצוא טיוטה אינו דורש אישור; יצוא טקסט מאושר דורש ביקורת עדכנית ללא חסימה ואישור אנושי מפורש. התמונה הנלווית נשארת טיוטה לבדיקה חזותית, גם כשהטקסט אושר.

## מקור חדש

הדבק כתבה או תמלול ובחר סוג. לחץ ״קריאת הטקסט״, תעד טענה עם קטע ראיה מדויק ומיקום. רק אם בדקת מול המקור הראשוני סמן זאת וציין שם בודק. שמור תיק תוכן, ערוך פוסט ומפה משפט לטענה. לפני אישור בדוק גם טענות שאינן ממופות: הבדיקה המבנית אינה מחליפה שיקול דעת.

״הכנת הנחיית כתיבה״ יוצרת brief לשימוש בעוזר או לכתיבה שלך; אינה מפעילה מודל. אין כרגע יצירה אוטונומית. ניסיון קריאה מקישור ייכשל במפורש כשאין גישה; לתוכן וידאו דרוש תמלול או חומר נגיש מתאים.

## בדיקות ופקודות נוספות

Linux/macOS:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 -m moh_ai --help
```

PowerShell:

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python -m moh_ai --help
```

פקודות Windows לא הורצו כאן. הנתונים נכתבים ל־data ומוחרגים מ־git; נדרש גיבוי נפרד לנתוני המשתמש. עצירה: Ctrl+C בטרמינל. אין פתיחת גישה לרשת הביתית או לשרת ציבורי.

## תמונה

בתיקיית pilot כבר נמצאת image.png. לרינדור PNG כללי קיימת פקודת render-image ב־CLI, הדורשת Pillow עם RAQM וגופן עברי מותקן ברישיון מתאים. אם הם חסרים, תקבל שגיאה מפורשת; אין fallback לשירות בתשלום. SVG ביצוא עובד ללא תלות זו. אין FFmpeg/MP4 כחלק מהגרסה הזו.
