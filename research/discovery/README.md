# איסוף מקורות אמיתי — RSS / Atom

מקטע יישום: 4 בנובמבר 2026. המודול משתמש בספרייה הסטנדרטית של Python ואינו מפעיל API או מודל AI בתשלום.

## מה בוצע בפועל

שלושה feeds ציבוריים של המפרסמים עצמם נקראו דרך מסלול ה־HTTP proxy המוגדר בסביבה. ניסוי הגישה החזיר 200 ו־XML בכל השלושה, והפקודה המלאה הפיקה `latest-report.json` עם `collection_method=rss` ו־`status=collected`.

| מקור | URL שנבדק | פריטים שנותחו בריצה |
|---|---|---:|
| OpenAI News | https://openai.com/news/rss.xml | 500 |
| Google AI Blog | https://blog.google/innovation-and-ai/technology/ai/rss/ | 20 |
| Hugging Face Blog | https://huggingface.co/blog/feed.xml | 500 |

שעת יצירת הדוח וה־SHA256 של תוכן כל feed נמצאים בדוח. ה־XML המלא לא נשמר במאגר, כדי לא לשכפל כתבות שלמות. נשמרו רק הכותרות והתקצירים הקצרים של הפריטים שנבחרו.

## מה נמצא בריצה

נותחו 1,020 רשומות metadata. לאחר ניכוי כפילות אחת, תאריכים ישנים והתאמה נמוכה, נבחרו **ארבעה מועמדים**. לא מולאה מכסה מלאכותית של חמישה. אלה כותרות והצעות זווית לפני קריאת הכתבה המלאה — לא פוסטים מוכנים ולא טענות מאומתות.

הפריטים שנבחרו כוללים נושאים של מעקב אחר שינויים במסמכים, יצירת מצגות, יישום AI בניהול נכסים והנדסה. הסינון נעשה בכללים ומילות מפתח בלבד. יש לבדוק בפועל איזה נושא מתאים למתחילים בקהילה.

## איך מריצים

משורש המאגר:

```bash
PYTHONPATH=src python3 -m moh_ai.discovery --output research/discovery/latest-report.json
```

PowerShell — מקבילה שלא הורצה בסביבה זו:

```powershell
$env:PYTHONPATH = "src"
python -m moh_ai.discovery --output research/discovery/latest-report.json
```

אפשר להגדיר `--sources <path>` לקובץ באותה סכמה, כדי לבחור אילו מן ה־feeds המאושרים פעילים. החלפת URL או הוספת publisher חדש דורשות הרחבת allowlist בקוד ובדיקת גישה; אין כאן fetcher פתוח לכל URL.

`--limit` מאפשר 1–5. `--now` מקבל זמן מפורש עם timezone לצורך בדיקה חוזרת של fixtures, לא לצורך שינוי תאריך פרסום אמיתי. אין להשתמש ב־now מומצא כדי להציג כתבה ישנה כחדשה.

## מה נשמר בכל מועמד

- URL קנוני ומזהה, שם מקור וכותרת.
- `published_at` של המפרסם בנפרד מ־`retrieved_at` ו־`generated_at`.
- `analysis_basis=metadata_only` ו־`verification_status=not_verified`.
- `content_status=needs_full_text`; מקור מסוג video מקבל needs_transcript כאשר יתוסף feed וידאו מאושר.
- ציון ונימוקים המבוססים על כללים, זווית מוצעת ופורמט מוצע.

תאריך חסר או ללא timezone נשאר לא ידוע ואינו מוחלף בזמן האיסוף. Atom updated אינו נחשב publication. פריטים עתידיים או ישנים מ־72 שעות אינם נבחרים. העדפה לפריטים בתוך 24 שעות, אחר כך הרחבה ל־72. נשמרות לכל היותר שתי הצעות מאותו מקור.

## רשת ובטיחות

הקוד מכבד HTTP_PROXY / HTTPS_PROXY ו־NO_PROXY. במצב proxy, פתרון DNS מתבצע על ידי ה־proxy הקיים עבור שלושת שמות המפרסם הקבועים; לא נעשה ניסיון לעקוף את ההגבלות. ללא proxy נדרשת בדיקת DNS ציבורי. אין כאן הבטחת IP pinning עבור מסלול proxy או עבור urllib במצב ישיר.

חסומים: URL feed שלא מופיע ברשימה, שינוי hostname ב־redirect, HTTP ללא TLS, credentials ב־URL, פורט אחר, DTD/entity ו־UTF-16, גוף גדול מ־2MiB וסוג תוכן שאינו XML. הקוד מוגבל ל־500 רשומות בכל feed; אין טענה לסריקת כל ההיסטוריה.

מגבלה: אין timeout קשיח נייד ל־DNS מקומי; timeout הרשת ותקציב הקריאה הם הגנות מוגבלות, לא התחייבות SLA. דפי כתבה ורשתות חברתיות אינם נקראים במודול הזה. אין עקיפת paywall או שימוש בחשבון פרטי.

## מה עדיין לא בוצע כאן

לא הוגדר תזמון יומי. לא נוצרה אוטומציה נוספת, לא הורחבו הרשאות, לא נכתב פוסט מתוך הכתבות האלו ולא נלמד הקול של עמית. לא בוצע חיבור לממשק החי; הסוכן הראשי משלב את הדוח ומסמן את שעת הריצה ומגבלותיו. ההפעלה המקומית המוכחת היא איסוף metadata בלבד.
