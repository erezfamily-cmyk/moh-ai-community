# מוח AI — ממשק חי פרטי

גרסת דפדפן סטטית של שולחן התוכן, המבוססת על הפיילוט והאפיון במאגר moh-ai-community.

## מה עובד

שולחן עבודה, פיילוט אמיתי, מקור וראיות, טיוטות, עריכה ושמירת גרסאות, ביקורת ידנית, אישור טקסט, יצירת PNG בדפדפן, הורדת Markdown וגיבוי/שחזור JSON. הוראות כתיבה אישיות אפשר לשמור; הן עדיין אינן מוזנות למודל.

הנתונים נשמרים ב־localStorage בדפדפן הנוכחי בלבד. אין מסד ענן ואין סנכרון אוטומטי בין מכשירים או עם היישום המקומי ב־Python. אפשר להעביר גיבוי בין מכשירים. אין לשלוח טענות אישור שלמות מתוך גיבוי כתחליף לאישור מחדש — היבוא מאפס אישורי טקסט.

אין כאן מודל AI, fetch אוטומטי של כתבות, סריקת בוקר או יצירת סרטון. אין API בתשלום או תלות בספק ענן ליצירת תוכן. האירוח הפרטי והגישה אליו תלויים בחשבון ChatGPT/Sites הקיים; אין הבטחת אירוח קבוע בחינם או גישה לאחר סגירת החשבון.

## מקור

הפיילוט בתיקיית dist/assets הועתק מהפרויקט המורשה; לא נוצר מחקר חדש. שלוש זוויות הבית הן וריאציות עריכה מאותו מקור, לא חדשות שנאספו היום. כל נתון חדש מוזן ידנית ומוצג ככזה. בדיקת מבנה היא היוריסטיקה, לא מבקר AI.

## בדיקות

`node --test tests/core.test.cjs`: 9 עברו. תחביר app.js ו־core.js נבדק.

ב־Cloud Browser נבדקו: פתיחת הבית, פתיחת עורך הפיילוט, שינוי כותרת ושמירת גרסה, רענון עם שימור הטקסט, היסטוריית גרסאות והורדת PNG. מקור ו־backup נבדקו בחוזי הליבה; טופסי מקור ושחזור קובץ לא נבדקו כאן מקצה לקצה.

התאמה ברוחב תוכן 390, 768 ו־1440 נבדקה באמצעות iframes של אותו אתר. בכולם scrollWidth שווה clientWidth. נבדקה חזותית תצוגת הבית במחשב; אין טענה שבוצעה בדיקה על מכשיר טלפון פיזי. דף QA זמני הוסר לפני הפרסום.

## תחזוקה

הקוד ב־dist אינו דורש build או dependencies. הפעלה מקומית דורשת HTTP server סטטי; פתיחה ב־file:// אינה מספיקה כי הפיילוט נטען בקובץ JSON. פרסום נעשה באמצעות מניפסט .openai/hosting.json ותהליך הפרסום של Sites, ללא פרסום ציבורי או שינוי הרשאות.
