## מה קרה בפועל

המקור הרשמי של OpenAI נקרא דרך חיבור GitHub MCP. נבחר רעיון אחד למתחילים. נכתבה v1, ואייג׳נט מבקר קרא את זרימת העבודה לכתיבת תוכן, בחן את הטיוטה והציע שיפורים. נשמרו ביקורת, ציונים, מיפוי טענות ו־v2. התמונה הופקה מקומית בכלי רינדור מבוסס Pillow, ללא שירות יצירת תמונות בתשלום.

זהו תוכן לימודי קבוע, לא חדשות מהיממה האחרונה. תאריך הפרסום של המקור לא אומת, ולכן נשמר null ולא הומצא תאריך חדש.

## איך לפתוח במערכת

משורש המאגר עם Python 3.11 ומעלה:

```bash
python start.py
```

פתח בדפדפן http://127.0.0.1:8765 ולחץ ״פתיחת הפיילוט הראשון״. יופיעו שתי גרסאות וביקורות. אין אישור עמית אוטומטי. הכתיבה בעורך ידנית או בעזרת סשן עוזר נפרד; מנוע יצירה מקומי ותזמון יומי עדיין אינם ממומשים.

## זכויות ומגבלות

הטקסט בעברית והדוגמה חוברו לצורך הקהילה; נשמרו רק קטעי ראיה קצרים מהמקור, לא העתק הכתבה. הכרטיס הוא המחשה מקורית עם מיתוג זמני. גופן DejaVu Sans הותקן בסביבת ההרצה ולא צורף כקובץ למאגר. אין בו תמונות צד שלישי, שיר או צילום מסך שמתחזה לכלי אמיתי.

לפני פרסום: עמית קורא, בודק שהסגנון מתאים לו, מאשר את נוסח הפוסט ובוחן את התמונה. אישור במערכת אינו פרסום חיצוני. ביקורת המבקר נשענת על תיק הראיות ועל קריאת המקור של הסוכן הראשי; אינה אימות עצמאי נוסף.
