# דוגמה מלאה למשתמשי מוח AI

תאריך: 4.11.2026. [פתיחת הדוגמה בממשק](https://moh-ai-editorial-lab.mentorysai-c-6274.chatgpt.site/#demo).

## מהלך העבודה בפועל

1. **בחירת פרויקט:** הכנת פוסט לימודי לחברי קהילה מתחילים, עם תרגיל ותמונה.
2. **מחקר וניתוח:** הפריט נבחר מ־research/discovery/latest-report.json, מזהה 8d86676710497099b1091deb. גוף הכתבה נקרא באמצעות כלי הגלישה, ובנוסף README של מאגר המחקר נקרא בהצלחה באמצעות GitHub MCP. נשמרו רק קטעי ראיות קצרים; הטענות נשענות על דיווח החוקרים ולא על שחזור הניסוי.
3. **תכנון וכתיבה:** brief.md מתעד את הקהל, המטרה והנחיית הכתיבה. הופעלו הנחיות moh-ai-editor. הכותב הוא העוזר בסשן; אין טענה שמודל מקומי יצר את הפוסט.
4. **בניית תוצר:** post-v1.md, post-v2.md, image.png ודוגמה מודרכת בממשק. התמונה היא תרשים מידע מדויק שנוצר ב־Pillow מקומי, ללא שירות מדיה או API בתשלום. הסקריפט render-image.py משחזר אותה עם גופן DejaVu Sans ו־RAQM. יש לשמר את רישיון הגופן המקומי כאשר מפיצים את הגופן עצמו; הוא אינו מצורף לחבילה.
5. **ביקורת ותיקון:** סאב־אייג׳נט demo_critic בדק v1 ואת evidence.json. review-v1.md מתעד שלושה ממצאים אמיתיים. v2 מבהירה את תחום הממצא ואת ההבדל בין המחשה, ממצא והצעת עבודה. הסוכן הראשי בדק שכל שלושת הממצאים קיבלו מענה, שמיפוי המשפטים מדויק ושהתרשים עקבי עם הדוגמה.

## קבצים ותפעול

- evidence.json: מקור, תאריך, בסיס הקריאה ושתי טענות עם קטעי ראיה ומיקומים.
- brief.md: בחירת זווית והנחיה.
- post-v1.md + review-v1.md + post-v2.md: רצף הגרסאות והתיקון.
- demo.json: מידע מובנה לדוגמה באתר, כולל מיפוי הטענות ותיקונים.
- integrations.json: תיעוד הפעלת הסקיל והחיבור החיצוני.
- image.png + render-image.py: כרטיס ההסבר ושחזורו.

הממשק מציג את הרצף ללא שינוי טיוטות קיימות. לחיצה על ״פתיחת עותק לעריכה״ מוסיפה עותק עם מזהה קבוע; לחיצה חוזרת פותחת את אותו עותק ומגינה על עריכותיו. הדוגמה המקורית נשארת זמינה. כרטיס היצוא הרגיל בעורך הוא תבנית אחרת; את תמונת התרשים המקורית מורידים ממסך הדוגמה.

## גבולות ההדגמה

אין אישור עמית לפרסום, אין פרסום חברתי ואין סרטון. הקול זמני. אין ביצוע בפועל של התרגיל במודל, ולכן לא מוצגת תוצאה כאילו התקבלה ממנו. התשובה נבדקה לוגית מול הטקסט בלבד. קריאת תיעוד המחקר אינה בדיקה עצמאית של הממצאים. הדוגמה מלאה במסלול פוסט+תמונה עם ביקורת; אישור אנושי הוא שלב פתוח בכוונה. סריקת בוקר אוטונומית עדיין נפרדת מהדגמה זו.
