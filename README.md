# מוח AI — שולחן התוכן של הקהילה

פרויקט מסכם: מצורך אמיתי לתוצר בעזרת AI, MCP וסקילים.

המערכת נועדה להפוך מידע אמין ומעניין לתוכן בעברית בגובה העיניים, עם פעולה קטנה שהקורא יכול לנסות. היא תתמוך בניתוח קישורים ובאיסוף יזום, ותפיק פוסט עם תמונת הסבר או סרטון מונפש מצילומי מסך, טקסט וסימונים.

**להתחלה:** [START_HERE.md](START_HERE.md) · [הרצת השלד](docs/FOUNDATION_QUICKSTART.md) · [עבודה מהעורכים](docs/EDITOR_SETUP.md).

## מעקב והצגת התהליך למנחה

פתח את [תיק המעקב למנחה](mentor/README.md): התפתחות הרעיון, החלטות, מצב חמשת שלבי התרגיל, יומן עבודה וראיות. זהו מסלול הקריאה המומלץ לבדיקת התקדמות.

## פתיחה במחשב שלך

```bash
git clone https://github.com/erezfamily-cmyk/moh-ai-community.git
cd moh-ai-community
```

פתח את התיקייה ב־Codex, VS Code או אנטיגרביטי. המאגר פרטי ודורש התחברות לחשבון בעל הרשאה; אין להדביק token בפקודה. העתק לעוזר את ההנחיה הבאה:

> קרא AGENTS.md, HANDOFF.md ו־prompts/BUILD_PROJECT.md. בדוק את שלד הקוד הקיים והמשך לפי docs/BUILD_PLAN.md. בצע את העבודה בפועל, שמור על אפס תשלום שירותים ועדכן HANDOFF בכל מקטע.

## גבול ההבטחה

זו חבילת בנייה של מסמכים, תצורות התחלתיות ושלד Python לבדיקת סביבה וייבוא מקומי; לא מערכת תוכן מוכנה. ראו [הרצת התשתית](docs/FOUNDATION_QUICKSTART.md). זמינות כל מקור, איכות מודל מקומי ויכולת המחשב נבדקות בזמן הבנייה. אין הבטחה שכל סרטון או פוסט ברשת חברתית נגישים.
