# יומן עבודה ולמידה

היומן מתעד עבודה בפועל. אין למחוק כשל או החלטה שהשתנו; מוסיפים רשומת המשך. תיאור המשתמש אינו תחליף לתוצאות בדיקה.

## 4.11.2026 — גיבוש הפרויקט

**מטרה:** לתרגם צורך בתוכן לקהילת ״מוח AI״ לפרויקט שמתאים לתרגיל.

**מה נעשה:** התחדדו סוגי המקורות, הקהל, הקול, שני פורמטי התוצר, מגבלת העלות וסריקת הבוקר. נכתבו דרישות, ארכיטקטורה, Super Prompt ותוכנית בנייה. הוגדרו שמונה תפקידי אייג׳נטים וחמישה מפרטי סקילים.

**מה למדנו/איזו הבחנה נוצרה:** סקיל או חיבור MCP אינם מבטיחים שהמודל שמפעיל אותם חינמי. ניתוח תמלול אינו שקול לצפייה בחומר החזותי. לכן צריך להפריד בין תוכנית, תצורה והפעלה שנבדקה.

**תוצרים:** [אפיון](../docs/PRODUCT.md), [עלויות](../docs/COST_POLICY.md), [אייג׳נטים](../docs/AGENT_SYSTEM.md), [Super Prompt](../prompts/SUPER_PROMPT.md).

**מה עדיין פתוח:** דוגמאות קול, פיילוט תוכן, מודל מקומי מתאים וחיבורים פעילים.

## 4.11.2026 — בניית תשתית ובדיקתה

**מטרה:** לאפשר המשך פיתוח מסודר בעורך קוד.

**מה נעשה:** נבנה שלד Python ללא תלויות runtime חיצוניות: בדיקת סביבה, יצירת SQLite וייבוא טקסט/תמלול מקומי. נוספו תיעוד, תבניות ותצורות אייג׳נטים התחלתיות.

**בדיקות בפועל:** שש בדיקות עברו; נבדקו גם doctor וייבוא דוגמה סינתטית. קישורים מקומיים ותחביר TOML נבדקו. [דוח](../docs/FOUNDATION_CHECKS.md).

**מגבלה שנשמרה:** אלה בדיקות שלד, לא פיילוט פוסטים ולא הפעלת MCP/Skill. דוגמה סינתטית אינה ראיית מחקר.

## 4.11.2026 — מעבר ל־GitHub

**מטרה:** להמשיך מ־Codex, VS Code או אנטיגרביטי.

**מה נעשה:** עמית יצר מאגר פרטי; התשתית הועלתה לענף main. אומתו 62 קבצים מול תוכנם המקומי בעת ההעלאה.

**ראיה:** [commit התשתית 7745732](https://github.com/erezfamily-cmyk/moh-ai-community/commit/77457324abcdfb27ff2976f1d02cc96d80b9601f).

**החלטה:** המאגר הזה הוא נקודת ההמשך. אין לפרסם את המאגר או להכניס אליו נתונים פרטיים כברירת מחדל.

## 4.11.2026 — תיק מעקב למנחה

**מטרה:** להראות את הדרך מהרעיון למימוש ולהבחין בין הישגים לבין תוכניות.

**מה נעשה:** נוסף תיק mentor עם סיפור ההתפתחות, סטטוס לחמשת השלבים, רישום ראיות ויומן זה. נוספה הוראה לעוזרי הפיתוח לעדכן את התיק בכל מקטע רלוונטי.

**בדיקה:** נבדקו קישורי המסמכים החדשים והקיימים המקומיים. שינוי זה הוא תיעוד בלבד; אין טענה שבוצעו בדיקות מוצר נוספות.

**הצעד הבא:** מקור אמיתי ותיק ראיות, טיוטה ראשונה וביקורת עם תיקון.
